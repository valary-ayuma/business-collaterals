# Business Collaterals Design Website

## Live Site

[business-collaterals.netlify.app](https://business-collaterals.netlify.app/)

A design portfolio website built for a freelance client to showcase their brand and print collateral work — business cards, brand kits, flyers, logo variations, and UX design pieces.

## Overview

This site was delivered as a freelance engagement to give a design client a professional web presence to display their portfolio. It's a multi-page site with a lightweight Node.js server component alongside the front-end.

## Tech Stack

- **Back-end:** Node.js (`server.js`)
- **Front-end:** HTML, CSS, JavaScript
- **Version control:** Git / GitHub

## Pages

- **Home** (`index.html`)
- **About** (`about.html`)
- **Services** (`services.html`)
- **Portfolio** (`portfolio.html`) — showcases collateral work: business cards, brand kits, flyers, logo sets, and UX pieces
- **Blog** (`blog.html`)
- **Contact** (`contact.html`)
- **Privacy Policy** (`privacy.html`) and **Terms** (`terms.html`)




## Getting Started

To run this project locally:

```bash
git clone https://github.com/valary-ayuma/business-collaterals.git
cd business-collaterals
node server.js
```

Then visit the local address printed in your terminal (commonly `http://localhost:3000`, depending on how `server.js` is configured).

> If `server.js` requires any npm packages, run `npm install` first. Add a `package.json` to the repo if one isn't already committed, so `npm install` works out of the box for anyone cloning it.
